# Textbook

The required textbook for GEOG 312 is:

> Wu, Q. (2025). _Introduction to GIS Programming: A Practical Python Guide to
> Open Source Geospatial Tools_. Independently published.
> ISBN 979-8286979455 (print), 979-8993859712 (PDF).
> <https://amazon.com/dp/B0FFW34LL3>

![book cover](https://assets.gishub.org/images/gispro-book-cover.png)

The chapters on this site follow the book chapter for chapter. The
[schedule](schedule.md) tells you which chapter to read before each week.

## Free Code Examples

Every code example in the book is free, regardless of whether you buy the book.
They live in the book's own repository at
[giswqs/intro-gispro](https://github.com/giswqs/intro-gispro) and are mirrored
on this course site, where each chapter page carries **Open in Colab** and
**Binder** badges. You can start working on day one while you sort out where to
get a copy of the text.

The book's own website is <https://gispro.gishub.org>.

## Video Tutorials

A companion series of video tutorials walks through the key concepts:

**<https://tinyurl.com/intro-gispro-videos>**

The videos were recorded in Fall 2024, when this course was last taught, and are
organized to follow the book's structure. They complement the written material
rather than replacing it, and they are especially useful for:

- Seeing code being written and executed rather than only reading it
- Hearing a second explanation of a concept that did not land the first time
- Watching how to approach a problem and debug it

Recordings from this semester are posted on
[Canvas](https://utk.instructure.com) as we go.

## Additional Reading

These are optional, freely available, and useful if you want a second take on
the Python fundamentals:

- Swaroop CH. _A Byte of Python_. <https://github.com/swaroopch/byte-of-python>
- Ujaval Gandhi. _Python Foundation for Spatial Analysis_.
  <https://courses.spatialthoughts.com/python-foundation.html>
- Dave Whipp. _Geo-Python_. <https://geo-python-site.readthedocs.io>
- Michael Dorman. _Introduction to Geospatial Programming with Python_.
  <https://geobgu.xyz/py/index.html>
- Qiusheng Wu. _Earth Engine and Geemap: Geospatial Data Science with Python_.
  <https://book.geemap.org>
